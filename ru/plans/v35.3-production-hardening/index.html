    v35.3 Production Hardening — Implementation Plan¶

    For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development

    Goal: Integrate research findings, fix bugs, add tests, and create international-quality documentation for opencode_initializer.

    Architecture: 4 independent blocks executed sequentially. Block A extends scripts with new MCP/LSP/plugins. Block D fixes hardcoded versions and bugs. Block B adds test coverage. Block C rewrites documentation to international standard.

    Tech Stack: Bash 5.x, Python 3.14 (inline), npm global, bun bin paths, ShellCheck CI

    Global Constraints¶

    • All scripts must pass bash -n syntax check
    • Every new feature must have real install commands (no stubs)
    • Tests: grep-based assert pattern (no real installations)
    • Docs: English (international standard), README ≤ 500 lines
    • Commit after every completed task (frequent commits)
    • No hardcoded secrets anywhere
    • Follow existing naming conventions (snake_case functions, 2-space indent)
