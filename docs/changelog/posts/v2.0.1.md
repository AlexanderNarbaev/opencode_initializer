# v2.0.1 — kimi-proxy v14.2: Dynamic Payload Compression

**2026-07-27** · **kimi-proxy v14.2**

Fixes Kimi/Moonshot API timeout issues caused by undocumented 20KB request body limit.

## Problem

Moonshot API (api.moonshot.ai) silently rejects requests with body size >20KB. OpenCode sends 400+ tool definitions and 100+ messages, resulting in 700KB+ payloads that timeout without any error response.

## Solution

kimi-proxy v14.2 dynamically compresses payloads to fit the 20KB limit:

- **Sticky tools**: `bash`, `read`, `write`, `edit`, `grep`, `glob` are always included first
- **Tool trimming**: max 10 tools, descriptions truncated to 80 chars, parameter schemas preserved
- **Message trimming**: last 15 messages, content truncated to 400 chars
- **Progressive fallback**: if still over 20KB, aggressively reduces to 3 tools + 5 messages + 100 chars
- **IPv4-only upstream**: Cloudflare IPv6 hang workaround
- **SSE streaming**: compatible with opencode's AI SDK
- **reasoning_content stripping**: prevents opencode 1.18.x hang bug

## Configuration

Environment variables for tuning:

```bash
KIMI_PROXY_MAX_TOOLS=10        # Max tools per request
KIMI_PROXY_MAX_MSGS=15         # Last N messages kept
KIMI_PROXY_MAX_MSG_CONTENT=400 # Max chars per message content
KIMI_PROXY_MAX_TOOL_DESC=80    # Max chars per tool description
KIMI_PROXY_MAX_BODY_KB=20      # Target payload size limit
KIMI_PROXY_TIMEOUT=600         # Upstream timeout in seconds
KIMI_PROXY_STRIP_TOOL_PARAMS=0 # Keep parameter schemas (set 1 to strip)
KIMI_PROXY_STICKY_TOOLS=bash,read,write,edit,grep,glob,task,fetch_fetch,webfetch
```

## Requirements

- **VPN is required** for stable connections to api.moonshot.ai (upload speed issue without VPN)
- **Moonshot API key** set via `MOONSHOT_API_KEY` environment variable

## Breaking Changes

- Removed obsolete proxy scripts: `kimi-proxy.py`, `kimi-proxy-fork.py`, `kimi-proxy-daemon.sh`, `kimi-proxy-autostart.sh`, `apply_all_clean.py`, `apply_moonshot_proxy_config.py`
- Default model changed from `opencode-go/kimi-k3` to `deepseek/deepseek-v4-pro` (Kimi available as secondary provider)
