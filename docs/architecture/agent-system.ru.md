# Архитектура системы агентов

## Обзор

OpenCode Initializer использует многоагентную архитектуру со специализированными ролями для различных задач.

## Роли агентов

### Командир (Оркестратор)
- Координирует все действия агентов
- Управляет параллельным выполнением
- Поддерживает состояние цикла
- Делегирует задачи специалистам

### Планировщик
- Планирование на уровне файлов
- Создание TODO
- Декомпозиция задач
- Анализ зависимостей

### Исполнитель
- TDD реализация
- Следует инструкциям Командира
- Генерация кода
- Написание тестов

### Рецензент
- Асинхронная верификация
- Интеграционное тестирование
- Обеспечение качества
- Ревью кода

## Протокол коммуникации

Агенты взаимодействуют через:
1. **Файловый IPC** — директория `.opencode/state/`
2. **WAL чекпоинты** — журнал предзаписи для сохранения состояния
3. **Делегирование задач** — структурированные объекты задач
4. **Агрегация результатов** — сбор и синтез результатов

## Модель безопасности

Каждый агент работает с:
- **Изолированное выполнение** — Docker контейнеры или MicroVM
- **Минимальные разрешения** — принцип наименьших привилегий
- **Аудит логирование** — все действия записываются
- **Управление секретами** — короткоживущие учетные данные
